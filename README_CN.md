# 多组学证据揭示 *ABC1K7* 调控椰子驯化中的防御释放与碳重分配

**作者：** 游宁焕†，凌黄生†，陈静，李文饶，黄梦醒，张宇，曹红星*，孙程旭*（`suncx@catas.cn`，ORCID：`0009-0007-9841-9000`）  
**单位：** 中国热带农业科学院椰子研究所（CRI-CATAS）、河南大学、中南大学湘雅医学院附属海口医院、海南大学  
**目标期刊：** *Plant Biotechnology Journal*（PBJ）  
**版本：** PBJ V39.1（2026-06-18）

## 核心亮点

- **五维多组学全景整合**：融合 X 射线 CT 无损表型组（7,686 张 DICOM 切片，跨度约 1,200 HU）、广泛靶向与非靶向代谢组、TMT 定量蛋白组、转录组与群体基因组。
- **防御向生长的碳代谢重分配**：野生高种 CK 同时高投入物理防御（7.9 mm 厚壳）与黄酮苷类化学防御，而驯化矮种 W5 释放防御程序，将碳源系统性重定向至核苷酸与氨基酸合成（如 dIMP 34.6×、L-脯氨酸 4.1×）及胚乳加速发育。
- **发育渠道化（Canalization）的转录定量指标**：34 个核心黄酮合成酶基因在生物学重复间的表达变异系数（CV）揭示，CK 在 TP2 处于高度受控的发育渠道化状态（CV = 0.172），而 W5（CV = 0.485，上升 182%）与 W6（CV = 0.579）表现为人工选择驱动的去渠道化（Decanalization）。
- ***ABC1K7* 主效选择清除**：群体遗传学将最强选择信号收敛至 Chr5:19.75–20.35 Mb 含 *ABC1K7* Y→F 错义突变的低重组祖先单倍型块（π 比值峰值 = 28.7；CDI ROH 在 W5 中占比 76%，CK 中为 59%）。

## 摘要

本研究整合 CT 表型组、靶向/非靶向代谢组、TMT 蛋白组、转录组与群体基因组五层互补数据，系统解析了改良矮种椰子（W5、W6）与地方高种（CK）果实发育的结构与代谢差异。基于约 1,200 HU 动态范围的 CT 发育时钟实现了对果实四层组织的无损追踪。代谢组与转录组共同表明，CK 维持高度渠道化的黄酮防御程序（TP2 核心酶 CV = 0.172），而 W5 发生调控释放（CV = 0.485），并将碳流重定向至核苷酸和氨基酸合成。群体基因组将全基因组最强选择清除（π 比值 = 28.7）定位于携带 *ABC1K7* Y→F 突变的 Chr5 低重组祖先单倍型块。本研究将生长–防御权衡范式拓展至多年生热带木本果树，建立了可复用的多年生作物驯化多组学研究框架。
